# Kalin — tải app

Kalin là siêu app nhắn tin, gọi thoại và gọi video của [trithuc.pro.vn](https://trithuc.pro.vn).

**Trang tải chính thức:** https://kalin.trithuc.pro.vn/tai-app

| Thiết bị | Cách cài |
|---|---|
| 🖥️ Windows 10/11 | Tải `Kalin-Setup.exe` ở mục [Releases](../../releases/latest) rồi mở file để cài. |
| 🤖 Android | Tải `Kalin.apk` ở mục Releases, hoặc cài từ CH Play khi app đã lên Google Play. |
| 🍎 iPhone / iPad | Mở kalin.trithuc.pro.vn bằng Safari → Chia sẻ → Thêm vào MH chính. |

Repo này chỉ dùng để phát hành bộ cài. Mã nguồn được giữ riêng.

## Bộ nhận diện thương hiệu

Thư mục `brand/` chứa logo và ảnh cho các kho ứng dụng:

- `logo.svg`: logo dạng vector, nét ở mọi kích cỡ.
- `logo-1024-trong-suot.png`: logo nền trong suốt.
- `store/google-play/`: biểu tượng 512 px và ảnh nổi bật 1024×500 cho CH Play.
- `store/app-store/`: biểu tượng 1024 px và các cỡ nhỏ hơn cho App Store.
- `store/microsoft-store/`: biểu tượng cho Microsoft Store.
